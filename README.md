# Marwan OS

تطبيق ويب عربي ثابت يعمل مع مشروع Supabase السحابي `omsgstolburwmziuyvtg`. الملفات في جذر هذا المجلد جاهزة للرفع إلى جذر مستودع GitHub Pages دون بناء أو `npm install`.

**حالة التسليم:** نسخة تشغيل قابلة للتجربة، وليست إصدارًا إنتاجيًا مكتملًا. يتضمن تسجيل الدخول عبر Google في الواجهة، لكنه يحتاج Client ID وClient Secret من مالك مشروع Google قبل أن يعمل. ينقصها أيضًا ملف الأيقونة الرسمية، مفاتيح Claude وGemini، وضبط عنوان GitHub Pages النهائي، واختبارات حساب حقيقي شاملة. اقرأ [TEST_REPORT.md](TEST_REPORT.md) قبل النشر.

## التشغيل

افتح المجلد بخادم ملفات ثابت؛ فتح `index.html` مباشرة من `file://` لا يتيح Service Worker أو مصادقة الويب بصورة صحيحة. بعد الرفع إلى GitHub Pages شغّل الموقع عبر HTTPS. افتح التطبيق وسجّل الدخول عبر Google نفسه على كل جهاز للحفاظ على مزامنة بيانات الحساب، واستخدم «الإعدادات» لاختيار المظهر وصلاحيات AI.

في الواجهة الحالية توجد تطبيقات للمهام، التقويم، الملاحظات، الدراسة، المدرسة، المشاريع، الأهداف، العادات، الصحة، المصروفات، العبادات، الأفكار، التحليلات والأتمتة. تُخزن العناصر في Supabase، وتُطبّق سياسات ملكية الصفوف على الحسابات. الوظائف المتقدمة التي لم تكتمل مذكورة صراحة في تقرير الاختبار.

## بنية الملفات

- `index.html` و`assets/`: واجهة ثابتة، مكتبة Supabase 2.117.3، وPDF.js 6.4.299.
- `config.js`: رابط Supabase والمفتاح العام وعنوان النشر النهائي.
- `manifest.webmanifest` و`sw.js`: أساس PWA. الأيقونات غير مضافة حتى وصول الصورة الرسمية.
- `supabase/schema.sql` ثم `supabase/actions.sql` ثم `supabase/security.sql`: مخطط قاعدة البيانات والسياسات النهائي القابل لإعادة التطبيق على مشروع نظيف.
- `supabase/functions/marwan-ai/index.ts`: وظيفة Edge منشورة في المشروع الحالي.
- `tests/`: اختبارات المنطق وقاعدة البيانات.

## النشر حسب طلبك

فك ضغط ZIP أولًا، ثم ارفع كل محتوياته إلى جذر مستودع GitHub، بما في ذلك مجلد `assets` كاملًا. اختر Settings → Pages → Deploy from a branch → main → /(root). رابط هذا المستودع هو `https://marwanywr3-lab.github.io/marwan-os-/`. لا ترفع ملف ZIP نفسه إلى GitHub Pages؛ لا يتم فكّه تلقائيًا.

لا يحتوي هذا الأرشيف على كلمة مرور قاعدة البيانات أو مفاتيح Claude/Gemini أو `service_role`.
